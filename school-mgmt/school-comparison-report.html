School-Exclusive Features

Features unique to each school — what they have that the others don't

PLG School — 6 Exclusive Screens

  • HPC Assessment Approval — Multi-tier approval for holistic assessment marks
  • Fee Master Approval — Principal/admin approval before fee structure goes live
  • New Concession Approval — Concession category change needs approval
  • Student Fee Category Approval — Fee category changes go through approval
  • Interview Students — Interview scheduling & management for admissions
  • Application Status Count Report — Count-wise admission status summary
Why PLG has these: PLG has a formal approval workflow structure — no fee or category changes without authorization. Also a competitive-exam focused school (NEET/JEE + HPC suggests CBSE CBE board).

DAV School — 8 Exclusive Screens

  • Online Enquiries — Parents submit enquiries from a public web portal
  • Send Bulk Application Link — Mass-email admission application links to enquiries
  • Online Application Status — Track applications submitted via online portal
  • Portal Login Access — Control which parents can access the student portal
  • Donation Collection — Separate module for development/donation fee collection
  • Collection Report (Class-wise) — Fee collection drilled down by class
  • Collection Report (Branch-wise) — Fee collection across branches
  • Projection Collection Report — Fee collection projection vs actual
Why DAV has these: DAV runs online admissions — parents apply from home. Also collects donation/development fees separately (common in DAV Trust schools). BlockEnabled=true means they use block-level academic grouping.

Chalo testv3 — 35 Exclusive Screens

  • Day Closure — End-of-day cash denomination counting & closure
  • Student Gate Pass + Report — Student exit tracking with parent notification
  • Refund Approval + Receipt + Report — Full fee refund workflow
  • Attendance Reason Master — Configurable absence reason codes
  • TM Boarding Point Master — Transport boarding stop management
  • Vehicle Document Master — Track vehicle insurance, permits, fitness
  • Transportation Dashboard — Live transport operations view
  • WorkFlow Approval — Generic workflow approval engine
  • Centum Report — Students scoring 100% in subjects
  • Class/Staff/Subject/Teacher-Wise Result Analysis — 5 analysis reports
  • Fee Collection Priority + Term Fees Summary
  • Auto Number Config — Configure receipt/admission number formats
  • Storage Extension — File storage management
  • + 20 more screens
Note: testv3 is the standard Chalo demo — it has features being tested/showcased. Schools may not have all of these enabled in production.

Platform Architecture (Common to All 3)

Technical foundation shared across all Chalo Schools instances

Frontend
  • AngularJS 1.x SPA (blankonApp)
  • KendoUI commercial components
  • ocLazyLoad for module loading
  • Handsontable (mark entry grids)
  • Multi-language support (EN/HI/TM/MR)
Backend
  • .NET ASMX Web Services
  • Each school = separate service instance
  • testv3: testv3service.chaloschools.in
  • PLG: testservice.chaloschools.in
  • DAV: davtestservice.chaloschools.in
AI / Integrations
  • AI: eduthalamus.ai/schoolapi/chalo_v4
  • Function: Text rephrasing (circulars)
  • Tally ERP export (PLG)
  • Focus ERP export (PLG)
  • Online payment gateway
