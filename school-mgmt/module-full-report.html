01 — Login & Authentication

How users sign in — admin password or OTP on phone

Admin Login Working Phone OTP Working 6 User Roles Auto Logout (token expiry) No Forgot Password No School Logo on Login Page
Simple View

What Works Now

  • Admin can log in with username and password
  • Parents and teachers can log in with their phone number + OTP
  • System knows who is a principal, teacher, parent, student — and shows them the right pages
  • When you logout, your old login token is deactivated — can't reuse it

What's Missing

  • No "Forgot Password" option for admin
  • Login page shows "School Mgmt" — not the actual school's name or logo
  • No eye icon to show/hide password while typing
  • Error message only shows as a small toast — not visible enough
Technical View

API Endpoints

POST/auth/login/adminbcrypt verify
POST/auth/otp/requestSupabase OTP
POST/auth/otp/verifyreturns JWT
POST/auth/refreshtoken rotation
POST/auth/logoutRedis blacklist

DB Tables

usersrefresh_tokens

Stack

JWT (access 15min) + Refresh tokens (7d) · Redis blacklist on logout · bcryptjs for password · Supabase Phone OTP · 6 roles: super_admin, school_admin, principal, teacher, parent, student

Simple Improvements

  • Add school name and logo on the login page
  • Add "Forgot Password" — admin gets reset link on email
  • Show/hide password button (eye icon)
  • Show error message clearly below the field, not just a small popup
  • Add "Remember me" checkbox to stay logged in longer

Technical Improvements

  • POST /auth/forgot-password → email OTP reset flow
  • School logo from DB on login page (GET /schools/branding)
  • Persist role in JWT payload for frontend routing
  • Rate-limit OTP requests (max 3 per 10 min)
  • Login audit log table (ip, user_agent, timestamp)

AI generates conflict-free timetable 5-day × 8-period grid view Substitution finder when teacher is absent Uses Claude AI (claude-sonnet-4-6) Must type UUID to select class No drag-drop editing No substitution UI on screen
Simple View

What Works Now

  • Click "AI Auto-Generate" — AI creates the full week schedule in seconds
  • AI makes sure no teacher is in two classes at the same time
  • Grid shows Monday to Friday with 8 periods — each cell shows subject + teacher
